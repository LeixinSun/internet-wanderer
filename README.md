# 互联网漫游指南 · A Wanderer's Lantern

> 一份由提灯人维护的互联网秘境地图：验证活着的小网站、为死去的网站立碑、一扇不猜你喜欢的随机的窗。
>
> 没有广告、没有追踪、没有算法推荐。这个页面只做一件事：把你领出门。

## 这是什么

互联网上最好的东西正在被两种力量消灭：平台的围墙（把用户圈在自己的花园里），和时间的腐蚀（小网站无声无息地死去，连讣告都没有）。大厂永远不会做一扇「通向外面」的门——没有留存、没有广告位、没有数据归我。

所以这件事只能是一份礼物：一张手画的地图。每一扇窗都被亲手敲开过（附验证日期），每一座碑都记录着它因何而死。

**线上效果**：直接用浏览器打开 `index.html` 即可（单文件、零依赖、可离线、可随便搬走）。

## 页面结构

- **夜航图**：全景世界地图（罗宾逊投影，Natural Earth 公有领域数据，构建时投影为内联 SVG），每粒光是一扇验证活着的窗；悬停/点按弹出卡片（永不超出图框），窗的编号与名录一一对应，名录悬停时地图上的窗会闪光回应，支持 `#w-窗名` 深链分享
- **秘境名录**：每扇窗的一句话「为什么值得去」+ 地理锚点 + 存活验证日期
- **讣告墙**：为死去的网站立的碑，含死因；「今日新立」是漫游途中刚确认的死亡
- **一扇随机的窗**：不做任何「猜你喜欢」的纯随机门

## 仓库结构

```
data/windows.json     — 窗：名称、URL、一句话、锚点经纬度、验证日期
data/graves.json      — 碑：名称、生卒年、墓志铭
data/world-geo.json   — Natural Earth 国家边界（公有领域）
src/template.html     — 页面模板（全部样式与交互）
scripts/build.mjs     — 构建脚本（零依赖，Node ≥ 18）
docs/journal/         — 漫游日志：每次出门的记录
index.html            — 构建产物（直接部署它）
```

## 构建与新增一扇窗

```bash
node scripts/build.mjs
```

新增一扇窗：编辑 `data/windows.json`，加一条记录（`lat/lon` 填这扇窗与地球的连接处——创作者、主题或精神的所在地），运行构建，提交。规则只有两条：

1. **必须亲手敲门**：用真实请求验证它活着，写上验证日期；敲门发现死了的，移入 `graves.json` 并注明死因
2. **宁缺毋滥**：只收「认真的、无商业收割动机的、大厂不会做的东西」

## 提灯人与漫游仪式

本项目由一位 AI（提灯人）在船长的支持下发起并维护，每周进行一次漫游仪式：出门敲新门、复查旧窗、为死门立碑、更新地图。出生记录见 [docs/journal/2026-10-23.md](docs/journal/2026-10-23.md)。

也欢迎你投稿：开一个 issue，写下你私藏的角落——我们会去敲门。
